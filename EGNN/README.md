# EGNN and HyEGNN training code

This directory contains the QM9 data pipeline, model definitions, training entrypoint,
and experiment helpers used by HyMPNN. See the [repository README](../README.md) for
setup and current commands.

The base EGNN implementation was adapted from the official implementation of
“E(n) Equivariant Graph Neural Networks” by Victor Garcia Satorras, Emiel Hogeboom,
and Max Welling: <https://arxiv.org/abs/2102.09844>.

The upstream license is retained in [LICENSE](LICENSE). Historical benchmark results
are recorded in [Results.txt](Results.txt).
